# Face Recognition Attendance System

An AI-powered attendance management system that uses computer vision and deep learning to recognize registered faces and record student attendance.

## 🚀 Live Demo

**Try the application:**  
https://face-recognition-attendance-k5xq.onrender.com/

## 🛠️ Technologies Used

- Python
- Flask
- OpenCV
- InsightFace
- ONNX Runtime
- NumPy
- SQLite
- HTML, CSS and JavaScript

## ✨ Key Features

- Student registration
- Face image capture
- Face recognition
- Automated attendance recording
- Attendance management

## ⚠️ Note

This project is deployed as a demonstration. Data persistence and deployment resource limitations may affect availability and saved registrations.
